# Image assets

The JobChat logo, favicon variants, Open Graph image, and Twitter card image
in this directory are project brand assets generated from
`../src/assets/logo.png`.

The social preview files use DejaVu Sans at build time only; no DejaVu font
binary is distributed in this repository.

- `og-image.jpg`: 1200 × 630
- `twitter-image.jpg`: 1200 × 600
- `logo.png`: 512 × 512
- `apple-touch-icon.png`: 180 × 180
- `favicon-32x32.png`: 32 × 32
- `favicon-16x16.png`: 16 × 16

Unsplash photographs used by the landing page remain remote resources and
are documented in the repository-level `THIRD_PARTY_NOTICES.md`.
