# 全网选题发现引擎

本文件定义了从"用户指令"到"可写选题清单"的完整搜索和筛选流程。目标：自动在全网找到最适合留学生求职口播稿的选题素材。

---

## 搜索触发条件

当用户的指令属于以下情况时，启动全网选题发现流程：
- "帮我找几个选题"、"最近有什么好选题"
- "这周写什么好"、"找点素材"
- 给出大方向但没有具体企业/政策名（如"写几篇关于秋招的"、"最近有什么留学生利好"）
- "帮我做一期XX主题的内容"（未指定具体企业/事件）

当用户已给出具体选题（如"写一篇华为秋招的口播稿"），则跳过选题发现，直接进入智能选型和写稿流程。

---

## 搜索策略

### 第一轮：热点招聘信息搜索

按以下关键词组合搜索，每组搜索取前5-10条有效结果：

| 搜索方向 | 关键词组合 |
| :--- | :--- |
| 央国企招聘 | "留学生 央企 校招 2026"、"国企 海归 招聘 最新" |
| 外企招聘 | "外企 留学生 秋招/春招"、"500强 校园招聘 海归" |
| 大厂招聘 | "互联网大厂 留学生 招聘"、"科技公司 校招 海归" |
| 管培生项目 | "管培生 留学生 2026"、"全球管培 校招 海归" |
| 招聘会 | "留学生 招聘会 最新"、"海归 专场招聘 报名" |
| 人才政策 | "留学生 人才政策 补贴 最新"、"海归 落户 新政" |
| 行业趋势 | "留学生 就业 热门行业"、"海归 高薪 赛道" |

### 第二轮：高价值信息源定向搜索

以下信息源出稿率最高，优先搜索：

| 信息源类型 | 具体来源 | 搜索方式 |
| :--- | :--- | :--- |
| 官方招聘平台 | 各企业官网招聘页、国家留学人才就业服务平台 | 搜索"XX企业 校园招聘 2026" |
| 人才政策发布 | 各城市人社局官网、教育部留学服务中心 | 搜索"XX城市 留学生 人才政策 2026" |
| 求职资讯平台 | 应届生求职网、实习僧、牛客网 | 搜索"留学生 校招 最新" |
| 社交媒体热点 | 小红书、微博、知乎 | 搜索"留学生 求职 热门话题" |
| 招聘会信息 | 各地人才市场、高校就业中心 | 搜索"留学生 招聘会 XX月" |

### 第三轮：时效性验证

对搜索到的信息逐条验证：
1. **截止日期检查**：如果招聘已截止，直接淘汰
2. **发布时间检查**：优先选择7天内发布的信息，30天以上的需要二次确认是否仍有效
3. **来源可靠性**：优先官方渠道，非官方信息需交叉验证

## 选题评估标准

对搜索结果按以下5个维度打分（每项1-5分），总分15分以上的选题值得写：

| 评估维度 | 5分标准 | 1分标准 |
| :--- | :--- | :--- |
| **留学生相关度** | 明确面向留学生/海归，有专属通道 | 泛招聘，与留学生无特殊关联 |
| **信息具体度** | 有企业名+岗位+薪资+截止日期 | 只有笼统的行业趋势描述 |
| **时效性** | 7天内发布，招聘进行中 | 已截止或超过30天 |
| **吸引力** | 高薪/名企/稀缺机会/政策红利 | 普通岗位，无明显亮点 |
| **差异化** | 近期未做过类似选题 | 与最近发布的内容高度重复 |

## 选题输出格式

筛选完成后，输出选题清单供用户确认：

```
## 本期选题推荐（共N个）

### 选题1：[选题标题]
- 类型：[选题类型]
- 核心信息：[一句话概括]
- 关键数据：[薪资/岗位数/截止日期等]
- 信息来源：[URL或来源名]
- 评分：留学生相关度X + 信息具体度X + 时效性X + 吸引力X + 差异化X = 总分XX
- 推荐理由：[为什么这个选题值得做]

### 选题2：...
```

## 从选题到成稿的衔接

用户确认选题后（或用户说"都写"/"全部写"），按以下流程衔接：

1. 对每个确认的选题，调用 `smart_matching.md` 的决策引擎，自动确定模板+钩子+篇幅
2. 如果是批量创作（3篇以上），先列出所有选题的"配置清单"，确保差异化
3. 按配置清单逐篇创作
4. 每篇创作完成后，进行质量自检

## 用户指令快捷映射

常见用户指令的快速响应方式：

| 用户指令 | 响应方式 |
| :--- | :--- |
| "帮我找5个选题" | 执行完整搜索流程，输出5个选题清单 |
| "最近有什么好写的" | 执行热点搜索，输出3-5个高分选题 |
| "写一篇关于XX的" | 跳过选题发现，直接搜索XX的具体信息，进入写稿流程 |
| "帮我写5篇秋招相关的" | 搜索秋招热点，筛选5个不同角度的选题，确认后批量写稿 |
| "今天写什么好" | 搜索当日/本周最新招聘动态和政策，推荐3个时效性最强的选题 |
| "帮我做一期XX城市的内容" | 定向搜索该城市的人才政策+招聘会+企业招聘，组合成1-3个选题 |
