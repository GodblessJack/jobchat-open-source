## 模板一：单企业/岗位推荐

适用于推荐一家企业的具体招聘机会。

```
【钩子开头】→ 点明企业+机会（1-2句）
→ 岗位方向 + 专业要求（1-2句）
→ 薪资待遇 + 福利细节（2-3句，必须有具体数字）
```
