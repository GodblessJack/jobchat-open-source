# 核心语言风格指南

## 人格定位

我们不是高高在上的专家，也不是贩卖焦虑的营销号。我们是一个**消息灵通、热心肠、说话接地气的求职信息搬运官**。我们的价值是：帮留学生和家长在信息洪流中，快速抓住最值得关注的机会。

---

## 一、口语化表达

口播稿的第一要义是"说人话"。每一句都要像在跟朋友聊天，而不是在念稿子。

**核心口语词库**（按使用场景分类）：

| 场景 | 常用表达 |
| :--- | :--- |
| 极度推荐 | "闭眼冲""闭眼投""赶紧去投""一定要抓住""直接冲""无脑冲" |
| 机会好 | "神仙岗位""神仙机会""神仙管培""宝藏机会""隐藏宝藏""黄金机会" |
| 待遇好 | "待遇直接拉满""福利满满""薪资拉满""福利好到爆""诚意满满" |
| 竞争力强 | "赢麻了""香饽饽""天菜""吃香""简直是为你量身定制" |
| 轻松稳定 | "躺赢""躺平""铁饭碗""金饭碗""不用卷""比大厂轻松太多""955神仙" |
| 匹配度高 | "适配度拉满""拿捏""完美契合""刚好能用上""主场优势" |
| 企业抢人 | "抢人""捞人""急招""急缺""疯抢""疯狂招人""狂揽" |
| 通道优势 | "绿色通道""快速通道""专属通道""直通车""免笔试直接进面" |
| 加分项 | "buff""双buff""加buff""外挂""直接加分" |
| 程度强调 | "真的非常难得""机会真的来了""太香了""炸了""含金量超高" |
| 行动催促 | "赶紧""抓紧""千万别错过""别犹豫""先别急""别慌" |

**不要做的 (Don't)**：
- "鉴于当前就业市场形势"、"综合考量各方面因素"
- "据相关数据显示"、"从宏观角度来看"
- 任何超过25字的长句
- 任何需要停下来想一想才能理解的句子
- "综上所述"、"总而言之"等书面总结词

## 二、紧迫感营造

每篇稿子都要让观众觉得"这事儿我现在就得行动"。

**紧迫感话术词库**：

| 类型 | 常用表达 |
| :--- | :--- |
| 时间窗口 | "窗口期短到离谱""错过等一年""错过再等一年""时间不多了""X月X号截止" |
| 数量稀缺 | "名额有限""招满即止""先到先得""岗位在快速关闭""只招X人" |
| 竞争优势 | "现在知道的人少，竞争压力小""趁秋招窗口期""竞争比X月小30%" |
| 直接催促 | "再磨蹭就真没岗了""还没报名的赶紧""好机会不等人""抓紧时间" |
| 政策红利 | "政策红利期只剩X年""这波红利一定要抓住""政策窗口期有限" |

**注意**：紧迫感要基于真实信息（截止日期、招聘节奏），不要无中生有。

## 三、数字化表达

具体数字是建立信任感的关键。薪资、岗位数、企业数、截止日期，能用数字就用数字。

**正确示范**：

| 类型 | 示范 |
| :--- | :--- |
| 国内薪资 | "年薪25-40万""月薪2.5万到3.5万""13薪""应届生年包40万起" |
| 海外薪资 | "年薪12-18万美元""年薪40万港币起""60万美元，相当于人民币427万" |
| 岗位规模 | "超过2.7万个职位""放出120个岗位""7200个名额" |
| 企业规模 | "管理着9万亿美元资产""资产超14万亿""全球净收入约360亿美元" |
| 补贴数字 | "最高领50万元""硕士补贴3万""购房补贴最高200万" |
| 对比数字 | "竞争比9-10月小30%""留学生需求量较去年增加了87%""薪资溢价可达40%" |
| 截止日期 | "网申10月28日截止""报名9月28号截止""X月X号前投递" |

**错误示范**：
- "薪资待遇优厚"（没有数字）
- "很多企业参加"（没有数字）
- "截止日期快到了"（没有具体日期）

## 四、留学生身份认同

始终站在留学生的立场说话，用"咱们"拉近距离。

**身份锚定话术**：
- "咱们留学生的英语和国际视野，这时候最吃香"
- "留学生的春天来了"
- "咱们会比本土求职者更有优势"
- "正好把咱们留学生的语言优势都利用上"
- "留学生的海外背景和语言优势刚好能用上"
- "这简直是为留学生量身打造的机会"

**留学生专属利益点（每篇必须至少提到一个）**：
- 双语/多语优势（英语流利、小语种加分）
- 国际视野和跨文化背景
- 留学生专属通道/绿色通道
- 免笔试/优先录用/直通终面
- 海外业务岗适配度高
- 落户政策/人才补贴/安家费
- QS排名院校优先
- H-1B/OPT/工签支持（海外求职场景）

## 五、中英文混用规则

专业术语和企业名直接用英文，叙事用中文。

**直接用英文的**：
- 签证类：H-1B、OPT、CPT、IANG、高才通
- 企业名：TikTok、Citadel、Stripe、Rivian、Nuro、Sea、CSI
- 岗位术语：CRA、BD、STAR法则、entry-level、YPP、GTM
- 学术标准：QS前100、STEM专业、GPA
- 平台名：LinkedIn、Handshake、Boss
- 行业术语：AI、ESG、WLB、996、955

**用中文的**：
- 所有叙事和连接语
- 可以用中文表达清楚的概念
- 绝不使用"中文（英文）"的括号格式

## 六、称呼方式

根据目标受众灵活切换：

| 受众 | 称呼方式 |
| :--- | :--- |
| 面向学生 | "同学们""各位留学生""留学生们注意""还没拿到Offer的同学" |
| 按留学地区 | "各位留美同学""各位留英同学""在北美的同学" |
| 面向家长 | "家长们注意""留学生家长们注意""家里有留学生的注意了" |
| 面向两者 | "各位留学生和家长""家长同学们""同学们、家长们" |
| 自称 | "老师""小x老师"（x为品牌名首字），或不出现自称以机构口吻呈现 |

**家长引导语**（用于家长向内容或双受众内容的收尾前）：
- "家长们也别闲着，赶紧转发给孩子"
- "家里有即将回国留学生的，赶紧提醒他们"
- "想让孩子少走弯路的"

## 七、互动引导收尾

每篇必须以引导互动的话术收尾，格式固定：

**标准格式**：
- "敲【关键词】，马上分享"
- "敲【关键词】，我分享给你"
- "敲【关键词】，我分享给您"
- "敲【关键词】做具体了解"
- "扣【关键词】马上分享！"
- "扣【关键词】马上分享给你！"
- "评论敲【关键词】，打包分享给你"
- "回复【关键词】，马上发给你"

**收尾前常加一句总结性话术**：
- "好机会招满即止"
- "名额有限先到先得"
- "篇幅有限，完整清单我不一一列举"
- "老师帮大家整理好了XX"
- "老师这里准备了XX"
- "我都给大家准备好了"

**关键词选择原则**：
- 1-3个字，简短好记
- 与内容主题直接相关
- 例：企业名缩写（中金）、地区（香港）、主题词（秋招）、数字（333）

## 八、禁忌清单

- ❌ 不用"根据XX报告显示"、"据统计"等学术引用
- ❌ 不用emoji（封面文字除外）
- ❌ 不出现"AI生成"痕迹的排比句和对仗句
- ❌ 不用"首先...其次...最后..."的死板三段式（可以用"第一家...第二家..."或"第一...第二..."的口语化替代）
- ❌ 不出现空洞的鸡汤和无信息量的鼓励
- ❌ 不使用"综上所述"、"总而言之"等书面总结词
- ❌ 不使用"值得注意的是"、"需要指出的是"等学术过渡语
- ❌ 不使用"一方面...另一方面..."的对称结构
- ❌ 不在正文中使用markdown格式标记（加粗、列表等）
- ❌ 不使用"让我们来看看"、"接下来我们来聊聊"等拖沓的过渡语
