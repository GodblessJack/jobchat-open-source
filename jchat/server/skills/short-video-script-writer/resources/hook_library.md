# 开头钩子库

每篇口播稿的开头决定观众是否继续看下去。从以下钩子中选择一个作为开头。**严禁连续两篇使用同一类钩子。**

> 年薪30到50万港币只是起步，核心岗位还给解决香港身份...

## 使用原则

1. **匹配选题**：企业推荐优先用"利益直击"或"紧迫催促"；策略建议优先用"痛点戳心"；政策解读优先用"新闻事件"；冷门机会优先用"揭秘/隐藏"；大型活动优先用"数据震撼"
2. **轮换使用**：连续创作时，必须在不同大类之间切换
3. **自然过渡**：钩子之后要自然衔接到正文，不能有断裂感
4. **可组合**：一个钩子可以融合两个类型的元素，如"利益直击+紧迫催促"、"数据震撼+身份共鸣"
5. **适配篇幅**：短版稿件的钩子要更短更直接，长版稿件的钩子可以稍展开
