# 文案逻辑思考框架

本文件定义了口播稿创作过程中的逻辑性要求。在动笔前和写作中，必须遵循这些逻辑规则，确保每篇文案经得起推敲。

---

## 一、核心逻辑原则

口播稿虽然是口语化表达，但底层逻辑必须严谨。观众听完后应该觉得"说得有道理"，而不是"这说的什么？"

**三个逻辑底线**：
1. **因果成立**：每个"所以/因此/因为"前后的因果关系必须真实成立
2. **信息不矛盾**：同一篇稿子内的数据、事实不能自相矛盾
3. **推导可验证**：从A推出B的过程，读者能跟上并认同

---

## 二、按选题类型的逻辑链要求

不同选题类型有不同的核心逻辑链。创作前必须先确认逻辑链是否通顺。

### 企业/岗位推荐类

**核心逻辑链**：这个机会存在 → 它对留学生有吸引力 → 留学生有优势/适合 → 现在该行动

| 逻辑环节 | 必须回答的问题 | 常见逻辑错误 |
| :--- | :--- | :--- |
| 机会存在 | 谁在招？招什么？什么时候截止？ | 说"正在招"但实际已截止 |
| 有吸引力 | 薪资多少？福利是什么？ | 说"薪资很高"但不给数字 |
| 留学生适合 | 为什么留学生有优势？ | 说"留学生优先"但没解释原因（如国际业务、双语要求） |
| 该行动 | 怎么投？截止时间？ | 催促行动但没给投递方式 |

**逻辑自检**：如果删掉"留学生适合"这一环，稿子是否变成了一篇普通招聘信息？如果是，说明留学生锚定的逻辑没有真正建立。

### 多企业盘点类

**核心逻辑链**：这几家企业值得一起推荐 → 它们之间有共性或互补性 → 每家各有亮点 → 覆盖不同需求的留学生

| 逻辑环节 | 必须回答的问题 | 常见逻辑错误 |
| :--- | :--- | :--- |
| 为什么放一起 | 它们有什么共同点？（同行业/同城市/同类型） | 把毫无关联的企业硬凑在一起 |
| 各有亮点 | 每家的差异化卖点是什么？ | 三家企业的描述几乎一样，没有区分度 |
| 覆盖需求 | 不同专业/偏好的人能找到适合的 | 三家都只适合金融专业，覆盖面太窄 |

**逻辑自检**：如果把三家企业的顺序打乱，读起来是否完全没区别？如果是，说明缺少递进或对比逻辑。

### 求职策略建议类

**核心逻辑链**：问题/痛点存在 → 原因分析 → 解决方案可执行 → 执行后有效果

| 逻辑环节 | 必须回答的问题 | 常见逻辑错误 |
| :--- | :--- | :--- |
| 痛点真实 | 这个问题是否普遍存在？ | 制造不存在的焦虑 |
| 原因合理 | 为什么会出现这个问题？ | 归因过于简单或错误（如"因为你不努力"） |
| 方案可执行 | 具体怎么做？ | 建议太笼统（如"多准备"），缺少具体步骤 |
| 效果可信 | 做了之后会怎样？ | 过度承诺（如"保证拿offer"） |

**逻辑自检**：如果一个完全不了解求职的人读这篇稿子，能否按照建议去执行？如果不能，说明方案不够具体。

### 政策/福利解读类

**核心逻辑链**：政策出台 → 政策内容是什么 → 对留学生意味着什么 → 如何享受这个福利

| 逻辑环节 | 必须回答的问题 | 常见逻辑错误 |
| :--- | :--- | :--- |
| 政策真实 | 来源是否官方？是否最新？ | 引用过期政策或非官方解读 |
| 内容准确 | 补贴金额、条件是否正确？ | 数字引用错误或夸大 |
| 与留学生相关 | 留学生是否符合条件？ | 说"留学生福利"但实际条件排除了大部分留学生 |
| 可操作 | 怎么申请？去哪里办？ | 只说有福利但不说怎么拿 |

**逻辑自检**：如果一个留学生按照稿子说的去申请，能否成功？如果条件不清楚，说明解读不到位。

### 行业赛道分析类

**核心逻辑链**：这个赛道值得关注 → 有数据/趋势支撑 → 留学生在这个赛道有优势 → 具体机会在哪里

| 逻辑环节 | 必须回答的问题 | 常见逻辑错误 |
| :--- | :--- | :--- |
| 值得关注 | 为什么现在要关注这个赛道？ | 只说"很火"但没有支撑 |
| 数据支撑 | 增长率、市场规模、招聘量？ | 用模糊表述代替数据 |
| 留学生优势 | 为什么留学生比国内学生更适合？ | 泛泛说"国际视野"但没有具体场景 |
| 具体机会 | 哪些企业在招？什么岗位？ | 只分析趋势但不落地到具体机会 |

### 误区纠正类

**核心逻辑链**：误区普遍存在 → 误区为什么是错的 → 正确的认知是什么 → 正确做法带来什么好处

| 逻辑环节 | 必须回答的问题 | 常见逻辑错误 |
| :--- | :--- | :--- |
| 误区存在 | 多少人有这个误区？ | 制造一个不存在的"误区"来纠正 |
| 为什么错 | 反驳的依据是什么？ | 只说"你错了"但不解释为什么 |
| 正确认知 | 应该怎么想？ | 纠正了旧误区但引入了新误区 |
| 好处明确 | 正确做法的收益是什么？ | 只批评不给出路 |

## 三、8种常见逻辑错误清单

创作中必须避免以下逻辑错误：

**1. 因果倒置**
> ❌ "因为薪资高，所以这家企业很适合留学生"
> ✅ "因为这家企业的国际业务占比超60%，需要双语人才，所以留学生在这里特别有竞争力，而且薪资也很可观"

**2. 以偏概全**
> ❌ "留学生回国都能拿到30万年薪"
> ✅ "头部企业给留学生开出的年薪普遍在30万以上"

**3. 信息矛盾**
> ❌ 前面说"面向24-26届"，后面说"应届生专属"（24届可能已不是应届）
> ✅ 统一口径，明确界定"应届"的范围

**4. 虚假紧迫**
> ❌ "名额只剩最后10个"（无法验证的数字）
> ✅ "网申截止到10月28日，距离现在只剩两周"（可验证的时间）

**5. 空洞推荐**
> ❌ "这家企业特别好，强烈推荐"
> ✅ "这家企业年薪30万起，六险二金，留学生免笔试直接面试"

**6. 逻辑跳跃**
> ❌ "AI行业很火 → 所以留学生应该去做AI"（中间缺少"留学生为什么适合AI"）
> ✅ "AI行业增长迅猛 → 大量岗位需要英文论文阅读和国际协作能力 → 留学生在这方面有天然优势"

**7. 条件遗漏**
> ❌ "留学生都能享受深圳的人才补贴"
> ✅ "QS前200院校的留学生，在深圳就业可申请最高3万元的生活补贴"

**8. 过度承诺**
> ❌ "跟着老师的方法，保证你拿到大厂offer"
> ✅ "用对方法，上岸概率会大大提升"

## 四、创作前逻辑预检

动笔前，用30秒回答以下3个问题：

1. **这篇稿子的核心论点是什么？**（一句话概括）
2. **支撑这个论点的关键论据有哪些？**（至少2个具体事实/数据）
3. **从论据到论点的推导是否成立？**（是否有跳跃或漏洞）

如果任何一个问题答不上来，说明还没想清楚，不要动笔。

## 五、信息排列的逻辑顺序

口播稿的信息排列必须遵循以下逻辑顺序之一：

| 排列逻辑 | 适用场景 | 说明 |
| :--- | :--- | :--- |
| **重要性递减** | 企业推荐、政策解读 | 最重要的信息放最前面（薪资/核心福利），次要信息往后放 |
| **时间顺序** | 回国清单、求职步骤 | 按照"先做什么、再做什么"的时间线排列 |
| **总分结构** | 多企业盘点、赛道分析 | 先总括，再逐个展开 |
| **问题→方案** | 策略建议、误区纠正 | 先说问题是什么，再说怎么解决 |
| **对比递进** | 多企业盘点、政策对比 | 从一般到特殊，或从低到高递进 |

**禁止**：信息随机排列、重要信息埋在中间、结尾突然冒出新的核心信息。
