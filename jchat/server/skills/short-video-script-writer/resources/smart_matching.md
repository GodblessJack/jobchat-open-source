# 智能选型决策引擎

本文件定义了从"选题方向"到"最终文案配置"的完整决策逻辑。目标：根据输入自动确定最佳的选题类型、结构模板、钩子类型和篇幅级别，确保每篇稿件的结构和开头都不重复。

---

## 第一步：选题类型识别

根据用户输入中的**信号词**，自动判定选题类型。如果命中多个类型，选择信号词匹配度最高的那个。

| 选题类型 | 信号词（命中任一即触发） |
| :--- | :--- |
| 企业/岗位推荐 | 具体企业名 + "招聘/秋招/春招/实习/校招/开岗" |
| 多企业盘点 | "几家/3家/对比/盘点/推荐N家" + 企业名列表 |
| 管培生项目专推 | "管培/管培生/领军人才/轮岗项目/培训生" |
| 招聘会/活动推荐 | "招聘会/双选会/人才交流会/专场/洽谈会/云聘会" |
| 求职策略建议 | "怎么/如何/技巧/避坑/心态/方法/步骤/误区" |
| 政策/福利解读 | "政策/补贴/落户/户口/人才引进/选调/编制" + 非城市聚焦 |
| 城市人才政策专题 | 城市名 + "政策/补贴/落户/人才/福利" |
| 行业赛道分析 | "赛道/行业/领域/方向/趋势/风口" |
| 国际组织/使领馆 | "联合国/世界银行/亚开行/使馆/领馆/国际组织/YPP" |
| 隐藏赛道揭秘 | "隐藏/冷门/宝藏/不知道/揭秘/被忽略" |
| 回国准备清单 | "回国/准备/清单/必做/学历认证/档案" |
| 家长向内容 | "家长/爸妈/父母/家里有留学生/帮孩子" |

**无法判定时**：询问用户"这篇稿子主要想传递什么信息？推荐机会、分享策略、还是解读政策？"

---

## 第二步：结构模板匹配

每个选题类型有一个**默认模板**和**可选变体**。默认模板是最常用的，变体用于避免重复。

| 选题类型 | 默认模板 | 可选变体（用于防重复） |
| :--- | :--- | :--- |
| 企业/岗位推荐 | 模板一：单企业推荐 | 模板十：隐藏赛道（如果企业冷门）；模板五：策略建议（如果侧重"为什么值得投"） |
| 多企业盘点（2-3家） | 模板二：多企业盘点 | 模板三：大型合集（如果信息量大）；模板八：赛道分析（如果按行业分类） |
| 多企业盘点（4家+） | 模板三：大型合集 | 模板二：精选3家重点讲 |
| 管培生项目专推 | 模板一：单企业推荐 | 模板三：大型合集（如果盘点多个管培项目） |
| 招聘会/活动推荐 | 模板四：招聘会推荐 | 模板三：大型合集（如果推荐多场活动） |
| 求职策略建议 | 模板五：求职策略 | 模板十三：误区纠正（如果核心是纠偏） |
| 政策/福利解读 | 模板六：政策解读 | 模板七：城市政策（如果聚焦单城市） |
| 城市人才政策专题 | 模板七：城市政策 | 模板六：政策解读（如果政策是全国性的） |
| 行业赛道分析 | 模板八：赛道分析 | 模板二/三：多企业盘点（如果侧重推荐具体企业） |
| 国际组织/使领馆 | 模板九：国际组织 | 模板一：单企业推荐（如果只推一个机构） |
| 隐藏赛道揭秘 | 模板十：隐藏赛道 | 模板八：赛道分析（如果侧重行业分析） |
| 回国准备清单 | 模板十一：回国清单 | 模板五：策略建议（如果侧重行动建议） |
| 家长向内容 | 模板十二：家长向 | 模板十三：误区纠正（如果核心是纠正家长认知） |

**防重复规则**：连续创作3篇以上时，如果连续2篇使用了同一模板，第3篇必须切换到"可选变体"。

---

## 第三步：钩子类型推荐

根据选题类型和内容特征，推荐最佳钩子类型。每个选题类型有**首选**和**备选**两档。

| 选题类型 | 首选钩子类型 | 备选钩子类型 |
| :--- | :--- | :--- |
| 企业/岗位推荐 | 利益直击（薪资/福利/门槛） | 紧迫催促（窗口期/名额）、新闻事件（企业动作） |
| 多企业盘点 | 数据震撼（规模数字） | 利益直击（福利诱惑）、身份共鸣（留学生专属） |
| 管培生项目专推 | 利益直击（薪资/发展） | 新闻事件（企业动作）、揭秘隐藏（冷门好项目） |
| 招聘会/活动推荐 | 数据震撼（企业数/岗位数） | 紧迫催促（时间紧迫）、身份共鸣（留学生专属） |
| 求职策略建议 | 痛点戳心（焦虑共情/反常识） | 身份共鸣（留学生身份）、揭秘隐藏（信息差） |
| 政策/福利解读 | 新闻事件（政策落地） | 利益直击（补贴数字）、数据震撼（补贴金额） |
| 城市人才政策专题 | 新闻事件（城市放大招） | 利益直击（补贴诱惑）、数据震撼（岗位规模） |
| 行业赛道分析 | 数据震撼（增长数据） | 痛点戳心（认知刷新）、揭秘隐藏（冷门赛道） |
| 国际组织/使领馆 | 揭秘隐藏（隐藏通道） | 利益直击（薪资数字）、新闻事件（项目启动） |
| 隐藏赛道揭秘 | 揭秘隐藏（隐藏通道/冷门宝藏） | 痛点戳心（反常识）、数据震撼（薪资对比） |
| 回国准备清单 | 身份共鸣（家长喊话） | 痛点戳心（误区揭露）、紧迫催促（时间窗口） |
| 家长向内容 | 身份共鸣（家长喊话） | 痛点戳心（认知刷新/行为纠偏）、新闻事件（政策红利） |

**钩子轮换强制规则**：
1. 连续2篇不得使用同一大类钩子
2. 连续5篇内，7大类钩子至少使用3类
3. 批量创作时，在输出前列出每篇使用的钩子编号，确认无连续重复

---

## 第四步：篇幅自动判定

根据内容复杂度自动判定篇幅级别：

| 判定条件 | 篇幅级别 |
| :--- | :--- |
| 推荐单个企业/岗位/政策 | 短版（120-200字） |
| 推荐2-3家企业、单城市政策、招聘会、策略建议 | 标准版（200-300字，目标250字） |
| 盘点4家以上企业、多场活动、深度策略、回国清单 | 长版（300-450字） |

**核心原则：所有篇幅严格控制在1分钟以内（最多450字）。** 标准版目标250字，宁短勿长。信息量大时优先精简而非加长。

用户明确指定篇幅时，以用户要求为准。

---

## 第五步：内容差异化检查

批量创作时，在动笔前先列出每篇的"配置清单"，确保差异化：

```
第1篇：选题类型=企业推荐 | 模板=单企业 | 钩子=利益直击#1 | 篇幅=短版(~160字)
第2篇：选题类型=多企业盘点 | 模板=多企业 | 钩子=数据震撞#28 | 篇幅=标准版(~250字)
第3篇：选题类型=策略建议 | 模板=策略建议 | 钩子=痛点戛心#17 | 篇幅=标准版(~250字)
...
```

检查规则：
1. 相邻两篇的钩子大类不同
2. 相邻三篇的结构模板不完全相同
3. 每篇的标题句式有明显差异（疑问句、感叹句、陈述句交替）
