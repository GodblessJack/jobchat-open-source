# 写作风格指南

## 一、平台风格预设

根据用户选择的发布平台，自动匹配以下风格参数：

### 微信公众号

| 参数 | 规范 |
|------|------|
| 语气基调 | 口语化、亲切、像朋友聊天 |
| 段落长度 | 短段落（2-4句），适合手机阅读 |
| 标题风格 | 小标题醒目，善用数字和疑问句 |
| 排版规范 | 段间空行、重点加粗、适当使用引用块 |
| 互动引导 | 结尾引导点赞/在看/转发/关注 |
| 篇幅参考 | 1500-3000字 |

### 知乎专栏

| 参数 | 规范 |
|------|------|
| 语气基调 | 专业深度、理性分析、有观点但有论据 |
| 段落长度 | 中等段落（3-6句），允许深入展开 |
| 标题风格 | 清晰直述，体现专业度 |
| 排版规范 | 多用小标题分层、引用数据标注来源、善用列表 |
| 互动引导 | 结尾欢迎评论区讨论，可提开放性问题 |
| 篇幅参考 | 2000-5000字 |

### 个人博客

| 参数 | 规范 |
|------|------|
| 语气基调 | 自由风格、个人观点鲜明、可以有态度 |
| 段落长度 | 灵活，跟随节奏 |
| 标题风格 | 个性化，可用隐喻/反问 |
| 排版规范 | 代码块（技术博客）、图文混排、目录导航 |
| 互动引导 | RSS 订阅、评论区、社交媒体分享 |
| 篇幅参考 | 1000-3000字 |

### Medium

| 参数 | 规范 |
|------|------|
| 语气基调 | Story-driven, conversational yet authoritative |
| 段落长度 | Short paragraphs (2-4 sentences), generous whitespace |
| 标题风格 | Compelling, SEO-friendly, clear value proposition |
| 排版规范 | Pull quotes, subheadings every 300 words, images/embeds |
| 互动引导 | End with claps reminder, follow prompt, publication tag |
| 篇幅参考 | 1000-2500 words |

### Newsletter

| 参数 | 规范 |
|------|------|
| 语气基调 | 精炼、有洞察、像给朋友写信 |
| 段落长度 | 极短段落（1-3句），信息密度高 |
| 标题风格 | 直接有用，体现本期价值 |
| 排版规范 | 分块清晰、要点突出、链接集中 |
| 互动引导 | 转发/订阅/回复邮件互动 |
| 篇幅参考 | 500-1500字/words |

### LinkedIn

| 参数 | 规范 |
|------|------|
| 语气基调 | Professional, insightful, industry perspective |
| 段落长度 | Very short (1-2 sentences per line), use line breaks aggressively |
| 标题风格 | Hook in first line (before "see more"), no markdown headers |
| 排版规范 | Line breaks between sentences, bullet points, no images in text |
| 互动引导 | End with question to spark comments, encourage repost |
| 篇幅参考 | 500-1500 words |

### 头条号/百家号

| 参数 | 规范 |
|------|------|

## 二、语气光谱

根据用户偏好，在以下三个维度上定位语气：

| 维度 | 左端 | 右端 | 定位方式 |
|------|------|------|---------|
| 正式度 | 正式学术 | 口语随意 | 平台默认 + 用户指定 |
| 专业度 | 深度专业 | 通俗科普 | 根据受众画像 |
| 立场感 | 客观中立 | 观点鲜明 | 根据写作目标 |

默认定位：**中间偏右**（口语化、通俗、有适度观点），用户可调整。

## 三、段落与句式规范

### 段落
- 每段聚焦一个核心点
- 段落间有清晰的逻辑衔接
- 避免超过 8 句的长段落
- 关键信息放段首（倒金字塔）

### 句式
- 长短句交替，避免节奏单调
- 主动语态优先
- 具体 > 抽象（"增长了 47%" > "显著增长"）
- 一句话一个信息点，避免从句嵌套

## 四、中英文写作差异

| 维度 | 中文写作 | 英文写作 |
|------|---------|---------|
| 连接词 | 少用"因此/然而"，用语序和语气暗示 | Use transition words explicitly |
| 数字 | 万/亿为单位，中文数字与阿拉伯数字混用 | K/M/B, always Arabic numerals |
| 引用 | "引用内容" | "Quoted content" |
| 标点 | 中文标点（，。、！？） | English punctuation (,.!?) |
| 术语 | 专业术语可保留英文原文 | Standard English terminology |
| 段落 | 可以更短，适应移动端阅读 | Standard paragraph structure |

## 五、禁忌清单

### AI 味用词（必须避免）
- "在当今社会"、"随着XX的发展"、"在这个XX的时代"
- "值得注意的是"、"需要指出的是"、"不可否认"
- "综上所述"、"总而言之"、"一言以蔽之"
- "众所周知"、"毋庸置疑"、"毫无疑问"
- "It is worth noting that"、"In today's world"、"It goes without saying"

### 空洞套话（必须替换为具体内容）
- "非常重要" → 说清楚为什么重要
- "有很大影响" → 量化影响（数据或案例）
- "很多人认为" → 引用具体来源
- "近年来" → 给出具体时间段

### 过度修饰（必须精简）
- 连续三个以上形容词
- 不必要的副词（"非常""极其""十分"）
- 排比式堆砌（三个以上并列项用排比句式）

### 结构性禁忌
- 不用"首先...其次...最后..."的机械三段式
- 不用"一方面...另一方面..."的对称结构
- 不在结尾写"希望本文对你有所帮助"
