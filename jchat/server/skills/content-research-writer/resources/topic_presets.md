# 主题分类写作指南

每个主题分类对应特定的信息源推荐、写作角度、受众画像和引用偏好。根据用户选择的主题分类，加载对应指南辅助研究和写作。

---

## 1. 科技/AI

| 维度 | 指南 |
|------|------|
| 高价值信息源 | arXiv 论文、Google AI Blog、OpenAI Blog、MIT Technology Review、The Verge、Wired、机器之心、量子位、36氪 |
| 常见写作角度 | 技术科普（降维解释）、趋势预测、工具评测对比、行业影响分析、伦理探讨 |
| 目标读者画像 | 技术从业者、产品经理、创业者、对科技感兴趣的大众 |
| 引用偏好 | 数据驱动 — 优先引用论文数据、基准测试、官方发布 |
| 推荐结构 | 趋势分析型、How-to 教程型、对比分析型 |

**搜索关键词构造提示**：技术名 + benchmark/performance/comparison、技术名 + use cases/applications、技术名 + 2025/2026 trends

## 8. 健康/生活

| 维度 | 指南 |
|------|------|
| 高价值信息源 | PubMed、WHO、Mayo Clinic、Healthline、丁香医生、果壳、柳叶刀 |
| 常见写作角度 | 健康科普（循证医学视角）、生活方式建议、心理健康引导、运动/营养指南 |
| 目标读者画像 | 健康关注者、都市白领、家长、慢性病患者 |
| 引用偏好 | 数据驱动 — 必须引用权威医学/科学来源，避免经验之谈 |
| 推荐结构 | 问题-解决方案型、清单型、How-to 教程型 |

**搜索关键词构造提示**：症状/话题 + research/study/evidence、健康话题 + guidelines/recommendations、topic + systematic review/meta-analysis

**特别注意**：健康类内容必须标注"仅供参考，不构成医疗建议"，引用必须来自同行评审来源。
