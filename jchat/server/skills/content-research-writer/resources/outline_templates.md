# 大纲模板库

根据写作目标和主题特点，从以下 8 种模板中选择最匹配的一种。每种模板附带结构说明、适用场景和骨架示例。

---

## 模板1：问题-解决方案型

**适用场景**：读者有明确痛点，文章提供解决方案。如"如何提升远程办公效率"、"解决团队沟通低效的方法"。

**结构骨架**：

```
# [标题：直接点明要解决的问题]

## Hook — 痛点共鸣/数据冲击
## 问题定义 — 这个问题的本质是什么、影响有多大
## 根因分析 — 为什么会出现这个问题（2-3个根因）
## 解决方案 — 具体可执行的方案（3-5个要点）
  ### 方案1：[名称]
  - 操作方法
  - 预期效果
  - 案例/数据支撑
  ### 方案2：[名称]
  ...
## 实施建议 — 优先级排序、快速起步指南
## 结语 — 总结核心观点 + 行动号召
```

---

## 模板2：How-to 教程型

**适用场景**：教读者完成一个具体任务，步骤清晰可操作。如"从零搭建个人博客"、"用 ChatGPT 提升写作效率的 5 步法"。

**结构骨架**：

```
# [标题：How to / X步完成XX]

## Hook — 完成后的成果展示或反差对比
## 前置准备 — 需要的工具/知识/条件
## 步骤详解
  ### 步骤1：[动作]
  - 具体操作
  - 常见错误提醒
  - 示例/截图描述
  ### 步骤2：[动作]
  ...
  ### 步骤N：[动作]
## 进阶技巧 — 2-3个提升效果的额外建议
## 常见问题 — FAQ 或 Troubleshooting（可选）
## 结语 — 鼓励行动 + 延伸资源
```

## 模板3：观点论述型（Thought Leadership）

**适用场景**：作者有独特观点或洞察，需要说服读者。如"为什么大多数 AI 创业公司会失败"、"远程办公不是未来，混合办公才是"。

**结构骨架**：

```
# [标题：鲜明的观点陈述]

## Hook — 反常识陈述或争议性开场
## 核心论点 — 一句话总结你的观点
## 背景铺垫 — 为什么现在讨论这个话题（趋势/事件）
## 论据展开
  ### 论据1：[支撑点] — 数据/案例/研究
  ### 论据2：[支撑点] — 数据/案例/研究
  ### 论据3：[支撑点] — 数据/案例/研究
## 反方观点回应 — 诚实面对反对意见，逐一回应
## 延伸思考 — 如果这个观点成立，意味着什么
## 结语 — 重申观点 + 呼吁思考或行动
```

## 模板4：对比分析型

**适用场景**：帮读者在多个选项中做决策。如"React vs Vue vs Svelte 2025"、"公立学校 vs 国际学校"。

**结构骨架**：

```
# [标题：A vs B / 全面对比XX]

## Hook — 选择困难的场景共鸣
## 对比框架 — 说明对比的维度和方法论
## 选项概览 — 每个选项的一句话定位
## 逐维度对比
  ### 维度1：[名称]
  - 选项A 表现
  - 选项B 表现
  - 小结/胜出者
  ### 维度2：[名称]
  ...
## 综合对比表 — 表格形式汇总
## 选择建议 — 不同场景下的推荐（"如果你是XX，选A；如果你需要XX，选B"）
## 结语 — 核心结论
```

## 模板5：案例研究型

**适用场景**：深度分析一个具体案例，提炼可复用的经验。如"Notion 如何做到 0 广告获客 3000 万用户"、"瑞幸咖啡的逆袭复盘"。

**结构骨架**：

```
# [标题：XX的案例/复盘/启示]

## Hook — 案例中最震撼的结果或反差
## 背景 — 主角是谁、面临什么处境
## 挑战 — 遇到了什么问题/困难
## 策略与执行 — 做了什么、怎么做的（2-4个关键动作）
  ### 关键动作1：[名称]
  - 具体做法
  - 背后逻辑
  ### 关键动作2：[名称]
  ...
## 结果 — 用数据说话（增长/收入/用户数/市场份额）
## 可复用的经验 — 提炼3-5条对读者有用的 takeaway
## 结语 — 更广泛的意义或思考
```

## 模板6：趋势分析型

**适用场景**：分析行业或领域的发展趋势。如"2026年AI行业十大趋势"、"远程办公的下一个十年"。

**结构骨架**：

```
# [标题：XX趋势/预测/展望]

## Hook — 最具冲击力的趋势预判或数据
## 宏观背景 — 当前处于什么阶段、关键驱动力
## 趋势详解
  ### 趋势1：[名称]
  - 现状描述
  - 驱动因素
  - 预判 + 支撑数据
  ### 趋势2：[名称]
  ...
## 影响分析 — 这些趋势对从业者/企业/个人意味着什么
## 行动建议 — 如何提前布局（2-3个具体建议）
## 结语 — 总结性判断
```

## 模板7：清单型（Listicle）

**适用场景**：汇总多个同类项目，信息密度高。如"10个改变我工作效率的工具"、"创业者必读的 20 本书"。

**结构骨架**：

```
# [标题：N个XX / XX清单 / XX合集]

## Hook — 为什么整理这份清单 + 筛选标准
## 清单正文
  ### 1. [项目名]
  - 一句话介绍
  - 核心亮点/推荐理由
  - 适用场景/人群
  ### 2. [项目名]
  ...
  ### N. [项目名]
## 使用建议 — 如何从这份清单中获取最大价值
## 结语 — 欢迎补充/讨论
```

**注意**：清单不是简单堆砌，每个项目必须有筛选标准和推荐理由。

## 模板8：叙事型（Story-driven）

**适用场景**：通过讲故事传达观点或知识，适合个人品牌和 Medium 风格。如"我从大厂裸辞后学到的三件事"、"一个失败产品教会我的产品思维"。

**结构骨架**：

```
# [标题：故事性标题]

## 开场 — 关键场景或时刻（用画面感拉入）
## 背景铺垫 — 故事发生的背景
## 转折/冲突 — 遇到了什么问题/挑战
## 应对过程 — 做了什么尝试（包括失败的）
## 结果与顿悟 — 最终结果 + 关键领悟
## 提炼洞察 — 从个人经历升华到普遍适用的道理（2-3个）
## 结语 — 回到开场的呼应 + 留给读者的思考
```

**注意**：叙事型的核心是真实感和画面感，避免说教。先讲故事，再提道理。

---

## 模板选择指南

| 写作目标 | 推荐模板 |
|---------|---------|
| 解决读者具体问题 | 问题-解决方案型、How-to 教程型 |
| 说服读者接受观点 | 观点论述型 |
| 帮读者做决策 | 对比分析型 |
| 深度分析一个案例 | 案例研究型 |
| 预测行业走向 | 趋势分析型 |
| 汇总信息/资源 | 清单型 |
| 用个人经历传达洞察 | 叙事型 |
