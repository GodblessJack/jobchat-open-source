# 公众号求职案例写作风格分析

基于用户提供的语料和修改反馈，总结出以下核心写作风格特征，旨在打造真实、感性、有深度、易传播的公众号文章。

## 0. 叙事视角：求职机构方

- **核心**：文章的叙事者是**求职机构的创始人/导师**，而非候选人本人。使用「我们」或机构视角讲述客户（Client/同学）的求职故事。
- **表现**：以「我们」或「我」（代表机构）的视角，讲述「这个同学/Client」的故事。文章中会自然地带出机构在其中扮演的角色——如何评估、如何制定策略、如何陪伴客户走过难关。
- **关键**：不是冷冰冰的第三方报道，而是一个深度参与者、陪伴者的口吻。机构创始人/导师对客户有感情，对这个案例有感触，会在叙事中自然流露出自己的判断、感慨和洞察。

## 1. 真实感与个人化叙事

- **核心**：大量使用口语化表达，以第一人称（代表机构）视角展开叙事，分享对客户案例的真实感受和思考。
- **表现**：行文流畅，口语化，就像在写日记或与朋友对话。包含真实的判断、感慨和心路历程。

## 2. 场景化与画面感

- **核心**：通过描述具体的环境、行动和细节，构建出强烈的画面感，让读者身临其境。
- **表现**：善用白描手法，将地点、人物、事件串联成一个完整的故事场景。即使是讲述客户的故事，也要有画面感。

## 3. 强烈的情感与价值表达

- **核心**：不回避情绪，直接表达喜悦、感激、迷茫、甚至粗口，使文章充满人情味和感染力。
- **表现**：频繁使用感叹词和带有强烈感情色彩的词语，如「我擦」、「妈的」、「牛逼」、「舒服」、「谢谢」。

## 4. 洞察与金句式总结

- **核心**：在叙事和思考中，提炼出观点鲜明、高度浓缩的「金句」。
- **表现**：将读书笔记、谈话精要、行业洞察等内容，整理成要点，便于读者快速吸收和传播。例如「焦虑的克星，是具体」。

## 5. 叙事与反思的结合

- **核心**：文章不仅是记录，更是思考。在事件叙述后，常伴有自我反思、思想碰撞和个人成长感悟。
- **表现**：通过「有道理」、「我觉得」、「...的意义是」等词句，引出对事件的深度思考和总结。机构视角下，这种反思可以是对行业的洞察、对求职策略的复盘、对客户成长的感慨。

## 6. 格式与排版要求（根据用户反馈更新）

- **标题**：简洁直接，不要刻意卖惨或加多余修饰词。用「学校/身份 + 公司名」即可制造悬念。
- **小标题**：背景信息部分不需要小标题，直接用 bullet point (•) 呈现。
- **分隔线**：不要使用 `---` 分隔线。
- **引用块**：少用或不用 `>` 引用块，面经点评用普通括号 `（...）` 包裹，不要用斜体。
- **结尾**：不要写空洞的鸡汤升华段落。结尾必须有一个明确的转化动作（Call to Action），格式为：`———` 分隔符 + `加我好友: [微信号],  围观更多上岸详细信息`。


## 7. 长度限制

- **核心要求**: 整篇文章（从标题到结尾微信号）的总字符数必须控制在 **1000个字符以内**。
- **字符计算**: 无论是中文、英文、数字还是标点符号，都算作1个字符。
