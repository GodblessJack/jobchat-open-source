# 故事引擎 (v3.0)

本指南是 wechat-case-study-writer Skill v3.0 的核心。它提供了一个动态生成故事的框架，旨在取代 v2.0 的“菜单轮换”模式，让每一篇文章都拥有独一无二的灵魂。

## 1. 核心矛盾识别器 (Core Conflict Identifier)

在动笔前，首先要从学员的案例中识别出最核心的、最独特的矛盾点。这决定了整个故事的基调和走向。

| 矛盾类型 | 描述 | 案例特征 |
|---|---|---|
| **认知错配** | 学员对行业、岗位或求职本身有错误或狭隘的认知。 | 来自非目标行业，对目标岗位工作内容不了解，求职策略单一。|
| **技能短板** | 明显缺乏目标岗位所需的某项关键硬技能。 | 面试时在特定技术环节（如A/B Test, System Design）反复失败。|
| **软实力缺失** | 技术能力足够，但沟通、表达、讲故事的能力很差。 | 能解出算法题但无法向面试官解释思路，BQ环节表现糟糕。|
| **项目经验匮乏** | 简历空洞，缺乏与目标岗位相关的、有深度的项目。 | 面试时被问到项目经历就卡壳，无法展现自己的思考。|
| **心态崩溃** | 经历多次失败后，极度不自信，甚至自我怀疑，濒临放弃。 | 面试时紧张、焦虑，表现失常，言语中透露出对求职的恐惧。|
| **跨界转行** | 从一个完全不相关的领域转行，需要重塑整个知识体系。 | 本科专业与求职方向毫无关联，缺乏行业“黑话”和背景知识。|

## 2. 故事弧光生成器 (Story Arc Generator)

根据识别出的“核心矛盾”，动态地为故事生成一个独特的叙事结构（弧光）。

| 故事弧光 | 描述 | 适用矛盾 |
|---|---|---|
| **“顿悟”时刻** | 故事高潮是学员在某个关键时刻（如一次模面、一次谈话）突然想通了某个道理，从而扭转局势。 | 认知错配、软实力缺失 |
| **“绝境逢生”** | 故事着重渲染学员在多次失败后几乎放弃的绝望感，以及最终抓住机会成功上岸的戏剧性。 | 心态崩溃、屡败屡战 |
| **“强项致胜”** | 故事核心不是补短板，而是将学员的某一独特优势（如数学背景、行业热情、开源贡献）发挥到极致。 | 背景独特但有明显短板的学员 |
| **“慢工出细活”** | 故事强调的不是速成，而是长达数月的、扎实的准备过程，通过一个高质量的项目或持续的努力最终取胜。 | 项目经验匮乏、技能短板 |
| **“体系重塑”** | 故事的核心是学员如何在我们帮助下，系统性地学习、实践，最终完成从外行到内行的转变。 | 跨界转行、技能短板 |

## 3. 金句提炼器 (Quote Extractor)

结尾的金句**不能**从预设列表中选择，必须从生成的故事本身提炼出来，作为整个故事的点睛之笔。

- **原则**: 金句必须是故事核心思想的高度浓缩。
- **方法**: 问自己，“这个故事最想告诉读者的一句话是什么？”

| 如果故事弧光是... | 金句可能提炼自... |
|---|---|
| “顿悟”时刻 | “求职的本质，有时就是捅破一层窗户纸。” |
| “强项致胜” | “与其做一个平庸的六边形战士，不如做一个顶尖的单项冠军。” |
| “慢工出细活” | “最快的路，就是最慢的路。” |
| “体系重塑” | “从入门到上岸，你需要的是地图，而不是零散的风景照。” |
