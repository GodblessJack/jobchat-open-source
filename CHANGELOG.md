# Changelog

All notable changes to JobChat will be documented in this file. The format is
based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the
project uses [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-10-16

### Added

- Initial open-source release candidate.
- AI contact conversations, group collaboration, realtime calls, file upload,
  and PostgreSQL-backed memory.
- Local JWT authentication and a pgvector-enabled PostgreSQL development stack.
- Repeatable database initialization and local demo-contact seeding.
- Landing, chat, call, and gateway modules with reproducible npm lockfiles.
- Apache-2.0 license, third-party notices, contribution guidelines, security
  policy, issue templates, and CI checks.
